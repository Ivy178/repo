# Upgrades
1) 查可升级版本
gcloud container get-server-config --region <REGION> --project <PROJECT_ID>
2) 升 control plane
gcloud container clusters upgrade <CLUSTER_NAME> --region <REGION> --master --cluster-version <VERSION> --project <PROJECT_ID>
3) 升 node pool
gcloud container node-pools upgrade <POOL_NAME> --cluster <CLUSTER_NAME> --region <REGION> --cluster-version <VERSION> --project <PROJECT_ID>

# Backup for GKE
GKE 集群做“可恢复快照”
Kubernetes 资源对象
比如 Namespace、Deployment、StatefulSet、Service、ConfigMap、Secret(按策略)、CRD/CR 等。
持久化数据(PV/PVC)
对应磁盘快照，适合数据库、监控数据(例如 Prometheus/Alertmanager)等有状态应用。

2) 创建 Backup Plan(备份计划)
在 GCP 控制台进入 Backup for GKE:
选择区域(region)
选择目标集群 (你要备份哪个 GKE)
选择备份范围:
全集群，或
指定 namespace(生产通常按 namespace 分)
设置是否包含:
Secret
卷数据(PV/PVC 快照)
设定调度(例如每天 02:00)
设定保留期(例如 30 天)

# Gateways, Services & Ingress
NodePort/LoadBalancer  service
1) 只集群内访问(默认)
type: ClusterIP
适合微服务内部互调。

apiVersion: v1
kind: Service
metadata:
  name: my-app-svc
spec:
  type: ClusterIP
  selector:
    app: my-app
  ports:
    - port: 80
      targetPort: 8080

3) 公网暴露(GKE 常用)
type: LoadBalancer
GKE 会自动创建云负载均衡器并分配外网 IP。

apiVersion: v1
kind: Service
metadata:
  name: my-app-svc
spec:
  type: LoadBalancer
  selector:
    app: my-app
  ports:
    - port: 80
      targetPort: 8080
